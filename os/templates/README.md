# Templates

The shapes your Caddy fills in as it works. It copies these; it never edits them.

| Template | Becomes | Written by | When |
|---|---|---|---|
| `BLUEPRINT-DIRECTIVES.md` | `BLUEPRINT-DIRECTIVES.md` | `/blueprint ingest` | at ingest, from the session |
| `ACCESS-MAP.md` | `ACCESS-MAP.md` | `/blueprint deep-dive` | first thing in the Deep Dive |
| `design-record.md` | `design/phase-N.md` | `/blueprint deep-dive` | the moment a phase design is approved |
| `SYSTEMS.md` | `SYSTEMS.md` | `/blueprint deep-dive`, `/blueprint build` | the first time anything outside the machine is touched |
| `amendments.md` | `amendments.md` | any skill | the first new idea after the session |
| `handoff-card.md` | a card in the conversation | `/blueprint deep-dive`, `/blueprint build` | whenever a step needs a person |
