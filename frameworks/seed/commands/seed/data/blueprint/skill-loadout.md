# Blueprint — Skill Loadout

## Recommended Tools

| Tool | Priority | Why |
|------|----------|-----|
| PAUL | required | The phase build engine. The design record graduates into one plan per opportunity, run by `/blueprint build` |
| BASE | required | The machine's memory and rules; every fact learned here lands in the graph and in `BUSINESS.md` |
| Skillsmith | recommended | When a phase design calls for a skill of the client's own (a draft, a triage, a start-of-day brief), author it to spec instead of improvising |
| Connection recipes (`connections/`) | recommended | When the design's home is an outside tool, follow its recipe so the card stays short and the key never passes through chat |
